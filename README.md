# ✈️ Proxy Checker

**Приложение для Android, которое само находит рабочие прокси для Telegram.**

Если Telegram тормозит или не открывается без прокси — это приложение за пару
секунд соберёт свежие MTProto-прокси, проверит каждый на скорость и покажет
только рабочие. Тапнул по любому — он добавился в Telegram. Всё.

---

## 📲 Установка (только телефон, ничего больше не нужно)

### 1. Скачай APK
Открой эту ссылку **прямо на телефоне**:

### 👉 [**СКАЧАТЬ ProxyChecker.apk**](https://github.com/Kukurumbel/proxy-checker-android/releases/latest/download/ProxyChecker.apk)

Файл (~15 МБ) скачается сразу, без всякой регистрации.

### 2. Разреши установку
Открой скачанный файл `ProxyChecker.apk`. Телефон спросит разрешение на
установку из этого источника (браузера) — нажми **«Разрешить»** / **«Настройки»**
→ включи переключатель → вернись назад.

### 3. Установи и пользуйся
Нажми **«Установить»**. Появится приложение **Proxy Checker** с иконкой-самолётиком.

> На некоторых телефонах Samsung может предупредить, что приложение «от
> неизвестного разработчика» — это нормально для приложений не из Play Маркета,
> просто нажми «Всё равно установить».

---

## ▶️ Как пользоваться

1. Открой **Proxy Checker**.
2. Нажми **«Проверить все прокси»** — приложение само найдёт и проверит прокси
   (10–20 секунд).
3. Зелёные ● — рабочие, отсортированы по скорости (вверху самые быстрые).
4. **Тапни по рабочему прокси** — откроется Telegram и предложит его добавить,
   жми «Включить».
5. Готово — Telegram работает через прокси.

Кнопкой 📋 можно скопировать сразу все рабочие ссылки (например, переслать другу).

---

## ❓ Частые вопросы

**Это безопасно?**
Да. Приложение только читает открытые Telegram-каналы с прокси и проверяет их
связь. Оно не просит вход в Telegram, не собирает данные, ничего не отправляет.

**Почему не из Play Маркета?**
Это бесплатное приложение для своих, без аккаунта разработчика Google. Поэтому
ставится напрямую файлом — так же безопасно.

**Прокси не нашлись / все красные.**
Каналы с прокси иногда временно недоступны или прокси перегружены — просто
нажми «Проверить» ещё раз через минуту.

**Какие телефоны поддерживаются?**
Любой Android 8.0 и новее (это почти все телефоны).

## 🔧 Для тех, кто шарит (необязательно)

Приложение нативное, на Kotlin + Jetpack Compose. APK собирается автоматически
в GitHub Actions при каждом изменении и публикуется в
[Releases](https://github.com/Kukurumbel/proxy-checker-android/releases/latest).
Список каналов с прокси задаётся в `app/src/main/java/com/proxychecker/app/ProxyChecker.kt`
(переменная `CHANNELS`).
