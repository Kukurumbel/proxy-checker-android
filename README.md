# Telegram Proxy Checker — Android

Мобильная версия приложения для отбора рабочих MTProto-прокси. Делает то же,
что и `TelegramProxyChecker.exe`: читает публичные Telegram-каналы, проверяет
пинг каждого прокси и показывает рабочие. Тап по прокси — добавление в Telegram
в один тап.

Написано на Kotlin + Jetpack Compose. Минимальная версия Android — 8.0
(твой Samsung S25+ на Android 15 подходит с запасом).

---

## Как получить APK (сборка в облаке, без установки чего-либо на ПК)

На твоём компьютере НЕ нужно ставить Android Studio, SDK или Gradle. APK
собирается бесплатно на серверах GitHub. Нужен только бесплатный аккаунт GitHub.

### Шаг 1. Создай репозиторий на GitHub
1. Зайди на https://github.com и войди (или зарегистрируйся — бесплатно).
2. Нажми **New repository** (зелёная кнопка).
3. Имя — любое, например `proxy-checker-android`. Можно сделать **Private**.
4. **Не** добавляй README/gitignore — жми **Create repository**.

### Шаг 2. Залей этот проект в репозиторий
Открой терминал (в Claude Code это просто эта же сессия) и выполни — подставив
свой адрес репозитория вместо `<URL>` (его GitHub показывает на странице репо,
вид `https://github.com/ТВОЙ_ЛОГИН/proxy-checker-android.git`):

```bash
cd "C:/Users/79213/dist/android"
git init
git add .
git commit -m "Telegram Proxy Checker for Android"
git branch -M main
git remote add origin <URL>
git push -u origin main
```

При `git push` GitHub попросит логин и токен (не пароль!). Токен создаётся тут:
https://github.com/settings/tokens → Generate new token (classic) → отметь
галочку `repo` → скопируй и вставь вместо пароля.

### Шаг 3. Дождись сборки и скачай APK
1. На странице репозитория открой вкладку **Actions**.
2. Увидишь запущенный workflow **Build APK** — подожди ~3–5 минут (зелёная
   галочка = готово).
3. Открой завершившийся запуск → внизу блок **Artifacts** → скачай
   **ProxyChecker-apk** (это zip).
4. Распакуй zip — внутри `app-debug.apk`.

### Шаг 4. Установи на телефон
1. Перекинь `app-debug.apk` на Samsung (через кабель, Telegram «Избранное»,
   почту — как удобно).
2. Открой файл на телефоне. Android попросит разрешить установку из этого
   источника — разреши.
3. Готово, приложение «Proxy Checker» появится в меню.

> Это **debug**-сборка — её не нужно подписывать ключом, ставится сразу.
> Для публикации в Google Play понадобилась бы release-подпись, но для личного
> использования debug-APK полностью рабочий.

## Если что-то пошло не так
- **Сборка упала (красный крестик в Actions):** открой запуск, нажми на шаг с
  ошибкой, скопируй текст и пришли мне — поправлю.
- **APK не ставится:** проверь, что на телефоне разрешена установка из
  неизвестных источников (Настройки → Приложения → доступ → Установка
  неизвестных приложений).
- **Прокси не находятся:** каналы могут быть временно недоступны — попробуй
  позже или поменяй список каналов в `app/src/main/java/com/proxychecker/app/ProxyChecker.kt`
  (переменная `CHANNELS`).

```
├─ app/
│  ├─ build.gradle.kts            конфиг модуля (версии, зависимости)

│     │  ├─ ProxyChecker.kt       логика: сбор + проверка прокси

├─ build.gradle.kts               версии плагинов
└─ settings.gradle.kts            репозитории, модули
```
